# Bapsang — Bapsang 검증용 풀스택 앱 (Render 무료 티어용 독립형 재구축)

> **전부 테스트 모드입니다.** 실결제·실공급자 연동이 없습니다. 예약·결제·포인트·관리자
> 기능은 검증용 시뮬레이션입니다. 이 앱은 Muse 검증용 앱(`kfair-2`)을 Render에
> 배포할 수 있는 독립형 코드로 새로 만든 것입니다. 원본 아티팩트 소스는 읽지 않고,
> 공개 카탈로그 액션으로 확보한 데이터(`catalog.json`)를 기준으로 재구축했습니다.

## 기능 범위 (검증용과 동일)

- 카테고리 12개 고정 순서: 로컬 일상(DAILY), 음식점(FOOD), 술집(PUB), K-뷰티(KBEAUTY),
  숙박(STAY), 관광지 체험(SIGHTSEEING), 딜리버리(DELIVERY), 이동수단(RIDE),
  안경점(EYEWEAR), K-POP(KPOP), K-Drama(KDRAMA), 외국인 유료직업소개(JOBS).
  패키지 상품 없음, **의료 카테고리(피부과·성형외과) 없음**.
- 상품 38개, 택시 요금 노선 4개, KRW/USD 환율 1350.
- 예약 → 테스트 결제 → 확정 → 취소/환불. 서버에서 가격 재계산.
- 숙박: 날짜별 빈방 차감/취소 시 복원 (부팅일 기준 다음 14일치를 패턴 반복으로 재생성).
- 코인노래방: 곡 단위 500원/곡, 기본 10곡.
- 테스트 결제: 승인 카드 `4242…`, 거절 카드 `4000…0002`. 카드번호는 마지막 4자리만 저장.
- 택시: 최종가가 아니라 미터기 요금 (일반 기본 4,800원/1.6km, 대형·모범 7,000원/3.0km,
  통행료 분리, 운행 후 자동결제 개념).
- 후기 포인트: 방문 코드 확인된 후기에만 예약 금액 1% + 작성 보너스 100P, 미확인 후기 0P.
  후기는 이용 완료 후에만 제출 가능.
- 로컬 메이트: 예약 확정 후 7일간 예약별 지원 채널 (규칙 기반 정형 문안).
- 공급자 가입: 사업자등록번호 10자리 검증 → 관리자 승인/반려.
- 관리자: 예약·결제·매출 집계, 숙박 빈방 조정. **인증이 없습니다. 테스트용입니다.**
- AI (규칙 기반, 실제 모델 연동 없음): 하루 일정 에이전트(실상품 5슬롯), CX 상담봇
  (긴급 1분 이내 응답 목표 표시), AI 추천, 상품명·후기 번역 (번체 대만/홍콩 포함).
- 언어 7개: 영어(기본), 한국어, 일본어, 중국어 간체, 번체(대만), 번체(홍콩), 스페인어.
  언어 전환 버튼은 헤더에 상시 표시. 통화 KRW/USD.
- 지도 탭: 상품 38개 전체 동네 단위 핀 (핀은 동네를 표시한다 명시), 도시 칩
  (전체·서울·부산·제주), 카테고리 칩, 거리순 정렬, 길찾기 링크, 내 위치 찾기
  (브라우저 Geolocation, 실패 시 동네 칩 기준점 폴백).
- 상품 상세 고정 문구: `판매자: [공급자명], Bapsang는 예약 중개 플랫폼입니다`
  (샘플 상품은 `(검증용 샘플 공급자)` 병기). 안경점 상세에 '구입은 매장에서 이루어진다',
  직업소개 상세에 E-9 알선 금지·H-2 유료 알선 실질 금지·취업 가능 체류자격자 한정 고지.
- 이미지: Unsplash 직접 CDN 링크 (실물 사진 분위기), 실패 시 그라데이션 폴백. 일러스트 없음.
- 브랜딩: Bapsang만 사용. 타사 로고·문구 없음.

## 구조

```
hidden-gems/
├── render.yaml          # Render Blueprint: 무료 웹서비스 + 무료 Postgres
├── package.json         # 서버 의존성 (express, pg, pg-mem)
├── SPEC.md              # 재구축 명세
├── catalog.json         # 카탈로그 원본 (상품 38개, 노선 4개, 환율 1350)
├── server/
│   ├── index.js         # Express 진입점 (API + client/dist 정적 서빙, SPA 폴백)
│   ├── db.js            # DB 어댑터 (DATABASE_URL 있으면 실제 Postgres, 없으면 pg-mem)
│   ├── schema.js        # 스키마 자동 생성 + 카탈로그 seed (insert-if-empty)
│   └── routes.js        # API 라우트
└── client/              # Vite + React 프론트엔드 (leaflet 지도 포함)
    ├── src/             # App.jsx, api.js, i18n.js, map.jsx, utils.js, styles.css
    └── dist/            # 빌드 결과물 (npm run build로 생성)
```

## 로컬 실행

```bash
cd hidden-gems
npm install
npm run build        # client 의존성 설치 + Vite 빌드 → client/dist 생성
npm start            # 기본 포트 3000 (PORT 환경변수로 변경 가능)
```

브라우저에서 `http://localhost:3000` 접속.

- `DATABASE_URL`이 없으면 인메모리 DB(pg-mem)로 동작합니다. **서버를 재시작하면
  예약·결제·후기·포인트 데이터가 사라집니다.** 카탈로그는 부팅 때마다 다시 seed됩니다.
- 실제 Postgres로 테스트하려면 `DATABASE_URL=postgres://... npm start` 로 실행합니다.
  스키마 생성 + seed는 부팅 시 자동으로 수행됩니다.

## Render 배포 순서 (부모 에이전트 단계 — 이 저장소에서는 푸시·배포를 하지 않음)

1. 이 디렉터리를 GitHub 저장소로 푸시합니다.
2. Render 대시보드에서 **New → Blueprint** 로 저장소를 연결합니다
   (`render.yaml`이 무료 웹서비스 `hidden-gems` + 무료 Postgres `hidden-gems-db`를 정의합니다).
3. Blueprint가 `DATABASE_URL`을 웹서비스에 자동 연결합니다. 별도 환경변수 설정이 필요 없습니다.
4. 배포가 끝나면 Render가 발급한 URL로 접속해 카탈로그 38개와 예약 흐름을 확인합니다.

## Render 무료 티어 주의사항

- **웹서비스 슬립**: 15분 무활동 시 슬립, 첫 방문 시 약 1분 대기.
- **무료 Postgres 30일 만료**: 생성 30일 뒤 만료되고 14일 유예 후 삭제됩니다.
  만료 전에는 데이터를 백업하고 DB를 재생성하면 됩니다 (부팅 시 카탈로그가 자동 seed되지만,
  예약·후기·포인트 데이터는 백업하지 않으면 사라집니다). 장기 테스트에는 월 $6 유료 DB 전환을 검토하세요.
- **RAM 512MB**: 무거운 의존성을 쓰지 않았습니다. 빌드 시 `client` 의존성만 추가로 설치합니다.

## 알려진 한계 (배포 후 확인 필요)

- 로컬 검증은 pg-mem 경로로 수행했습니다. Render 실제 Postgres 경로는 배포 후
  카탈로그 38개 반환과 예약 1건으로 다시 확인해야 합니다.
- 언어 전환·지도·위치 찾기는 브라우저에서 최종 확인이 필요합니다 (사전은 7개 언어
  키 무결성 검사 완료, 지도는 haversine 거리순 단위 테스트 완료).
- 위치 권한이 거부된 경우, 원인별 괄호 문구(`permission denied` 등)는 영어로만 표기됩니다
  (본문 안내 문구는 번역됨).
- 관리자 콘솔에 인증이 없습니다. 공개 테스트 URL을 공유할 경우 접근 제한을 별도로 두세요.
- 무료 DB 만료 시 예약·후기·포인트 데이터는 소실됩니다 (카탈로그는 자동 재생성됨).
